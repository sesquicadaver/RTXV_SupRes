RTX VSR — Розширення кадру
Версія іконки: 1.0

Вміст:
  rtx-vsr.svg — основний векторний оригінал, viewBox 256 × 256.
  rtx-vsr.ico — Windows ICO: 16, 20, 24, 32, 48, 64, 128, 256 px.
  svg/ — окремо вирівняні версії SVG для 16, 20, 24 і 32 px.
  png/ — прозорі PNG RGBA для кожного з восьми розмірів.
  preview.png — огляд на світлому й темному тлі та збільшені малі версії.

Кольори:
  Основа: #171B21
  Контур кадру: #E9EEF4
  Стрілка: #A6E22E

Стиль: плоский; без градієнтів, тіней, текстур і написів.
За межами заокругленої основи — прозорість.
Малі версії мають окрему геометрію для чіткішого відображення.
Для 16–32 px використовуйте готові відповідні розміри.
ICO містить вісім PNG-кадрів із 32-бітним кольором RGBA.

Перевірено: структура SVG, усі кадри ICO, відповідність PNG,
прозорість, вигляд на світлому й темному тлі, цілісність ZIP.
Відображення у Windows/Qt у цьому середовищі не запускалося.

Архів містить лише графічні ресурси та цей опис.
Файли проєкту і репозиторій не змінювалися.
